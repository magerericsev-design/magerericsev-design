# Confidentialité / Privacy

## Français
ZephyrFlix conserve localement une bibliothèque SQLite comprenant chemins, titres, tags, favoris et progressions. Ce profil est séparé des fichiers applicatifs. Le scan ne déplace ni ne renomme vos vidéos. Ne publiez pas votre profil.

Internet est facultatif. Si vous configurez TMDB, des titres et années sont transmis pour rechercher des métadonnées et illustrations ; les vidéos ne sont pas envoyées. La clé personnelle est enregistrée dans le gestionnaire d'identifiants Windows, pas dans SQLite ni le paquet. Les images déjà en cache restent utilisables hors ligne. Aucun essai authentifié avec une clé utilisateur n'est revendiqué.

Aucune télémétrie analytique ou collecte distante n'a été ajoutée. Les erreurs peuvent créer des journaux locaux contenant chemins et titres : les relire avant de les partager. L'import facultatif d'une ancienne bibliothèque utilise une copie sauvegardée et exclut les clés API.

Aide & retours prépare un brouillon via le gestionnaire de messagerie : projet, version et catégorie. Aucun fichier, journal, chemin ou titre de bibliothèque n'est ajouté automatiquement ; aucun envoi automatique. Vous choisissez les informations communiquées. Contact : **zephyr.essentiel@gmail.com**. Aucun délai de réponse garanti.

## English
ZephyrFlix stores a local SQLite library including paths, titles, tags, favourites and playback progress. The profile is separate from application files. Scanning does not move or rename videos. Keep the profile private.

Internet is optional. Configuring TMDB sends titles and years to search for metadata and artwork; video files are not uploaded. The personal key is held in Windows Credential Manager, not SQLite or the package. Cached artwork remains usable offline. No authenticated user-key test is claimed.

No analytics telemetry or remote collection has been added. Errors may produce local logs containing paths and titles; review them before sharing. Optional legacy import uses a backed-up copy and excludes API keys.

Help & feedback prepares a draft in the mail handler containing project, version and category. No file, log, path or library title is attached automatically; no email is sent automatically. You control what you communicate. Contact: **zephyr.essentiel@gmail.com**. No guaranteed response time.
