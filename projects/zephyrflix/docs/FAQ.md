# FAQ — FR / EN

## Français
**Où télécharger ZephyrFlix ?** La version de test gratuite 1.4 RC est présentée sur la [page officielle](https://eric-mager-lab.balmylily512.chatgpt.site/downloads/zephyrflix/). Ce candidat n'est pas une version stable ; l'essai sur un autre Windows x64 reste à faire.

**Est-ce gratuit et open source ?** L'utilisation est gratuite. Le code est privé et réservé pour le moment. Ce sont deux décisions distinctes.

**Y a-t-il des films fournis ?** Non. Vous choisissez vos propres fichiers vidéo locaux ; aucune plateforme de streaming n'est intégrée.

**Faut-il Internet ?** Les fonctions locales n'exigent pas Internet. Les métadonnées TMDB sont facultatives, requièrent une clé personnelle et transmettent titres/années au fournisseur. Les vidéos ne sont pas envoyées.

**VLC est-il inclus ?** **Setup x64 RC 1.4 : oui**, le lecteur VLC 3.0.24 sélectionné et le runtime Visual C++ sont inclus. **Ancien ZIP Portable RC : non**, VLC 3 x64 et le runtime Visual C++ doivent être présents séparément. Suivre le guide du paquet choisi.

**Tous les formats sont-ils garantis ?** Non. Plusieurs scénarios locaux ont été testés ; le résultat dépend du runtime, du fichier et du matériel. Le test sur un autre Windows x64 reste à faire.

**Mes fichiers vont-ils être déplacés ?** Le scan ne déplace ni ne renomme les vidéos. La bibliothèque conserve des références locales.

**Une identification PROBABLE est-elle appliquée ?** Elle attend votre confirmation. Les corrections manuelles sont protégées.

**Comment signaler un problème ?** Paramètres → Aide & retours, ou **zephyr.essentiel@gmail.com**. Relire le message et tout fichier joint ; aucun envoi automatique et aucun délai de réponse garanti.

**Faut-il un compte administrateur ?** Le Setup installe pour votre compte sans droits administrateur, avec raccourcis Bureau et menu Démarrer. La désinstallation conserve les données du profil. Windows 10 x64 1809+ et Windows 11 x64 sont ciblés.

## English
**Where can I download ZephyrFlix?** The free 1.4 RC test version is presented on the [official page](https://eric-mager-lab.balmylily512.chatgpt.site/downloads/zephyrflix/). This candidate is not stable; separate Windows x64 testing remains pending.

**Is it free and open source?** Usage is free. Own source code is private and reserved for now. Those are separate decisions.

**Are films supplied?** No. Select your own local video files; no streaming platform is integrated.

**Is Internet required?** Local features work without it. Optional TMDB metadata needs a personal key and sends titles/years to the provider. Video files are not uploaded.

**Is VLC included?** **Setup x64 RC 1.4: yes**, selected VLC 3.0.24 and Visual C++ runtimes are included. **Original Portable RC ZIP: no**, it requires external VLC 3 x64 and Visual C++. Follow the instructions for the chosen package.

**Are all formats guaranteed?** No. Local scenarios have been tested, but playback depends on runtime, file and hardware. Testing on a separate Windows x64 PC is still pending.

**Will my videos be moved?** Scanning does not move or rename videos. The library stores local references.

**Is a PROBABLE match applied?** It waits for your confirmation. Manual corrections remain protected.

**How do I report an issue?** Settings → Help & feedback, or **zephyr.essentiel@gmail.com**. Review your message and attachments; no automatic sending and no guaranteed response time.

**Is an administrator account required?** Setup installs for your account without administrator privileges and provides desktop and Start menu shortcuts. Uninstall preserves profile data. Targets Windows 10 x64 1809+ and Windows 11 x64.
